# Linguist v0.1.0

首个可安装的 Windows 桌面版本，统一了卡片、药丸、截图翻译和音乐界面的液态玻璃视觉与交互。

## 主要变化

- 重写无边框窗口的拖动、八方向缩放和连续圆角呈现，改善右边、下边及右下角缩放稳定性。
- 卡片与药丸支持自适应布局、中文输入、自动语言检测、多语言切换和请求防串线。
- 截图翻译直接显示在现有卡片中，按原文与译文逐行排版，并提供原图预览。
- 接入 Windows 系统媒体信息、封面、进度、歌词和上一首/播放/下一首控制。
- 新增页面比例面板、历史记录、Apple Intelligence 风格的柔和流光反馈与统一动效。
- 提供用户级 Windows 安装、开始菜单快捷方式和完整卸载。

## 验证

- Release 构建通过。
- 144 项 QML 布局与交互测试通过。
- 中文输入法、Windows OCR、翻译方向与异步请求一致性测试通过。
- 安装、从安装目录启动、基础真实窗口交互和卸载闭环通过。

系统媒体效果仍取决于播放器是否公开 Windows GSMTC 数据；Gemini、DeepL 和有道服务需使用者自行配置有效密钥。安装包暂未签名，可使用随附的 SHA-256 文件核对完整性。
