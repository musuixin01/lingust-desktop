# Linguist 视觉设计规范与 UI 系统指南 (Design System & Style Guide)

> **版本**：v1.2.0  
> **状态**：项目强制执行标准 (Mandatory Engineering Standard)  
> **适用范围**：所有前端组件、悬浮卡片、弹窗模态、原子控件及未来扩展视图

---

## 1. 设计哲学与核心基调 (Design Philosophy)

Linguist 是一款面向现代化桌面场景的高端生产力翻译与词典工具。其视觉语言的核心在于**“极简、克制、沉浸与高度聚焦”**：

- **桌面级毛玻璃拟物美学 (Frosted Glassmorphism)**：借鉴 macOS 原生层级与半透明磨砂质感，让应用悬浮在任意桌面背景、IDE 或阅读器之上时，既能清晰分离层次，又能自然融入宿主环境。
- **内容绝对第一 (Content-First & Optical Purpose)**：杜绝华而不实的装饰性花哨元素。每一个内边距、每一处微阴影、每一个字号阶梯都必须有明确的光学对齐与功能目的。
- **自适应几何连续性 (Adaptive Geometric Continuity)**：从大尺寸的多功能词典卡片，到极小尺寸的极简双行翻译，再到极薄的桌面悬浮药丸，卡片形态变化平滑，视觉权重自洽。
- **Anti-Slop（反 AI 套路）铁律**：严禁滥用大面积高饱和紫蓝渐变、禁止无意义的高光发光外阴影、严禁随意嵌套卡片（Cards inside cards），保持高级冷灰暗调与微光漫反射质感。

## 2. 色彩系统与色彩语义 Token (Color Palette & Tokens)

项目默认采用**深空微蓝冷调暗夜主题 (Deep Midnight Space)**，所有半透明材质基于白色漫反射光（White Alpha）与深色环境遮罩（Dark Alpha）构建。

### 2.1 基础材质与表面 Token (Surfaces & Glass Layers)

| Token 变量 / 类名 | 颜色值 / CSS 属性 | 适用层级与场景 |
| :--- | :--- | :--- |
| **画布底层背景** (`.frosted-glass-canvas`) | `#0a0a1a` 配合两处微弱的径向暗紫/洋红漫反射光晕 | 桌面仿真底层背景 |
| **主悬浮卡片背景** (`bg-white/10`) | `rgba(255, 255, 255, 0.10)` | 核心悬浮卡片、截图原地卡片 |
| **次级容器背景** (`bg-white/5`) | `rgba(255, 255, 255, 0.05)` | 语言选择胶囊、词性释义块、输入框外壳 |
| **深色悬浮抽屉** (`bg-slate-900/95` 或 `bg-[#0c0d14]`) | `rgba(12, 13, 20, 0.95)` | 设置模态弹窗、生词本抽屉、悬停多行展开浮层 |
| **模糊滤镜强度** (`backdrop-blur-3xl`) | `blur(40px)` 或 `-webkit-backdrop-filter: blur(40px)` | 悬浮卡片高斯模糊核心参数 |
| **微光外边框** (`border-white/20`) | `1px solid rgba(255, 255, 255, 0.20)` | 静止态卡片与容器边界 |
| **激活高亮边框** (`border-white/35`) | `1px solid rgba(255, 255, 255, 0.35)` | 拖拽中、获取焦点中、激活选态 |
| **内表面高光刻痕 (Specular)** | `inset 0 1px 0 rgba(255, 255, 255, 0.25)` | 为卡片顶部提供 macOS 般精细的物理倒角反光 |

### 2.2 文本与层级对比度 Token (Typography Colors)

项目严格保证 WCAG AA（对比度大于 4.5:1）的可读性规范，严禁在彩色背景上使用不可读的暗灰文字：

| 文本层级 | Tailwind Token | 不透明度 | 推荐使用场景 |
| :--- | :--- | :--- | :--- |
| **主要强调文本** | `text-white` | 100% | 单词拼写、翻译核心译文、标题、当前激活项 |
| **正文次要文本** | `text-white/85` ~ `text-white/90` | 85% ~ 90% | 词性中文释义、双语例句译文、输入框输入文字 |
| **辅助弱化文本** | `text-white/60` ~ `text-white/70` | 60% ~ 70% | 音标 IPA、双语例句英文原文、同反义词标签 |
| **占位与失效文本** | `text-white/35` ~ `text-white/40` | 35% ~ 40% | Input Placeholder、快捷键提示、清空按钮默认态 |

### 2.3 语义与功能强调色 Token (Semantic Colors)

| 功能语义 | 色值 Token | 实际应用场景 |
| :--- | :--- | :--- |
| **苹果红绿灯 (关闭/清空)** | `bg-red-400/80` (Hover: `bg-red-400`) | 标题栏红色按钮、删除生词本记录 |
| **苹果红绿灯 (最小化/药丸)** | `bg-amber-400/80` (Hover: `bg-amber-400`) | 标题栏黄色按钮、警告提示、生词收藏高光 |
| **苹果红绿灯 (刷新/成功)** | `bg-emerald-400/80` (Hover: `bg-emerald-400`) | 标题栏绿色按钮、复制成功勾选、连通测试通过 |
| **主要交互强调蓝 (Primary Accent)** | `text-blue-400`, `bg-blue-500` | 截图按钮、语言选择激活底色、聚焦外轮廓环光 |
| **高级紫色辅色 (Purple)** | `text-purple-400`, `bg-purple-500/20` | 双语例句标识、AI 语境模式标识 |

## 3. 排版与字体阶梯系统 (Typography System)

### 3.1 字体家族配比原则
1. **界面主无衬线体 (Sans-serif)**：
   - 优先调用系统级现代无衬线字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Segoe UI", Roboto, "Helvetica Neue", sans-serif`。
   - 适用于：标题、按钮文字、翻译主结果、控制栏。
2. **音标与数字等宽体 (Monospace)**：
   - 调用：`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`。
   - 适用于：音标 `/[ˈlɪŋɡwɪst]/`、快捷键指示符、时间戳。
3. **典范双语例句衬线体 (Serif)**：
   - 仅在双语例句原文或深阅读文学释义时搭配微量优雅衬线（如 `font-serif` 或 `Georgia`），增强阅读呼吸感。

### 3.2 字号与行距阶梯 (Scale & Line Height)

| 尺寸等级 | 字号 / 行高 | 适用元素 |
| :--- | :--- | :--- |
| **2XS** | `text-[9px]` ~ `text-[10px]` / `leading-none` | 紧凑模式音标、标签徽章、微型发音指示 |
| **XS** | `text-xs` (11~12px) / `leading-snug` | 紧凑例句、控制栏图标说明、辅助释义 |
| **SM** | `text-sm` (13~14px) / `leading-snug` | 搜索框输入文字、紧凑卡片翻译译文、释义主体 |
| **BASE** | `text-base` (15~16px) / `leading-tight` | 紧凑单词详情词条、模态窗主标题 |
| **LG** | `text-lg` (18px) ~ `text-xl` (20px) | 标准卡片大词条、极简模式放大的主译文 |

### 3.3 动态字号微调与输入规范 (Custom Font Sizing)
- **默认精致基准**：默认字号比例设为 `92%`（`customFontSize: 92`），使文本与界面在紧凑状态下自然呼吸，解决卡片偏小而字体显过大的失调问题；
- **全范围自由数值输入**：支持在 `60%` ~ `150%` 之间直接输入任意数字调节字号，并由 `effectiveFontScale = (customFontSize / 100) * fluidScale` 结合容器几何长宽平滑缩放；
- **行高与外边距数学收敛**：在动态紧凑模式（`isDynamicCompact`）下，全局行高严禁使用松散的 `leading-relaxed`，一律收窄为 `leading-tight` / `leading-snug`，行间距压缩为 `space-y-1.5` ~ `space-y-2`，外边距从 `p-4.5` 压缩至 `p-2.5`，确保内容区域即使被裁切也能完整阅读。

### 3.4 溢出排版与悬停跑马灯 (Hover-Scroll) 规范
- **禁止断行与硬截断**：按钮、Tab 标签、音标药丸内文字严禁换行、折字；
- **单行超出处理**：
  - 普通元素采用 `truncate`（`overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`）；
  - 核心翻译与输入框使用专用 `HoverScrollText` 组件：鼠标悬停时平滑双向来回滚动，速度固定为 `35px/s`，两端停顿 `600ms`，左右两端附加渐变遮罩 (`mask-pill-marquee`)。

## 4. 间距、栅格与圆角数学规约 (Spacing & Corner Math)

### 4.1 8pt 基础间距模数
项目全局基于 4px / 8px 的倍数步进：
- 极微间距：`gap-1` (4px), `gap-1.5` (6px)
- 标准间距：`gap-2` (8px), `gap-3` (12px), `gap-4` (16px)
- 区域段落间距：`p-3` (12px), `p-4` (16px), `p-6` (24px)
- **容器与按钮边距法则**：按钮水平内边距必须严格为垂直内边距的 2 倍（例如：`px-3 py-1.5` 或 `px-4 py-2`）。

### 4.2 圆角数学嵌套定律 (Nested Corner Radius Math)
**严禁随意拍脑袋设定圆角**。当一个圆角容器嵌套在另一个圆角容器内部时，内圆角半径必须满足：
$$\text{Inner Radius} = \text{Outer Radius} - \text{Padding}$$

#### 项目具体落地参数：
- **完整主卡片 (Outer Card)**：
  - 外层容器：`rounded-[32px]` (32px)
  - 容器内边距：`p-3` (12px)
  - 内部输入容器与词条区域：`rounded-[20px]` (32px - 12px = 20px)
- **极简模式卡片 (Minimal Card)**：
  - 外层容器：`rounded-2xl` (16px)
  - 内边距：`p-2` (8px)
  - 内部文本块：`rounded-lg` (8px)
- **药丸模式 (Pill Mode)**：
  - 全封闭半圆：`rounded-full` (9999px)
  - 内部搜索输入与按钮：`rounded-full`

## 5. 卡片几何多态断点系统 (Adaptive Geometry Breakpoints)

主悬浮卡片通过实时监测容器尺寸 ($W \times H$)，在不同几何边界下动态切换 UI 视觉策略：

```
+-------------------------------------------------------------------------+
| 1. 标准展开态 (Standard Mode)                                            |
|    - 边界: W >= 340px 且 H >= 240px                                     |
|    - 特征: 完整展示红绿灯、拖拽控制栏、语言选择器、音标发音、多词性释义、  |
|            双语例句、同义词标签与底部状态栏                             |
+-------------------------------------------------------------------------+
                                    │ 缩窄或收敛高度
                                    ▼
+-------------------------------------------------------------------------+
| 2. 紧凑模式与流式缩放 (Compact Mode & Fluid Scale)                     |
|    - 边界: W < 420px 或 H < 400px 或 settings.compactMode 开启           |
|    - 特征: 【内容绝对一致性】卡片变小过程中绝不删减任何核心释义、例句与同反义词；|
|            【流式等比自适应】采用数学因子 fluidScale 进行字号与内边距紧凑化压缩； |
|            【紧凑排版微调】外边距 p-2.5，间距 space-y-2，行高 leading-snug；     |
|            【字号自由微调】顶栏与设置项均支持直接键盘输入 60%~150% 任意字号；     |
|            【控件永久保留】红绿灯、引擎指示器、截图、固定、设置、复制及朗读永不消失 |
+-------------------------------------------------------------------------+
                                    │ 进一步极小化拉伸
                                    ▼
+-------------------------------------------------------------------------+
| 3. 极小极简模式 (Minimal Mode)                                          |
|    - 边界: H <= 145px 或 (W <= 240px 且 H <= 190px)                     |
|    - 特征: 【核心视觉保留】仅保留搜索输入框与译文结果；                  |
|            【色彩绝对统一】译文颜色严格统一为标准强调色 text-white/95，禁止绿色； |
|            【角落微感应浮动】严禁整条顶部感应，仅当光标进入最左上角或最右上角微型 |
|                              热区 (w-9 h-7，即 36px×28px) 时才弹出独立控制胶囊；  |
|            【溢出滚动保障】内容超出时支持 HoverScroll 悬停双向平滑滚动   |
+-------------------------------------------------------------------------+
                                    │ 点击黄色按钮或最小化
                                    ▼
+-------------------------------------------------------------------------+
| 4. 桌面胶囊药丸 (Pill Mode)                                             |
|    - 边界: 手动点击最小化 或 高度 <= 48px                               |
|    - 特征: 38px~60px 超薄高透药丸，支持向上收缩高度，向下大幅度展开；    |
|            【防误触发卡片】上推缩小时高度可低至 38px，向下位移 >85px 才展开回卡片；|
|            【放大按钮可靠性】最右侧放大及功能按钮位于 z-50 顶层，阻止事件冒泡；   |
|            【超窄药丸点击保障】即使药丸拉至极小 (<280px)，搜索图标始终保留 28px   |
|                                独立胶囊靶心，点击聚焦瞬间平滑展开为输入框；      |
|            【左侧收缩规避】左侧红绿灯感应区收缩至边缘 16px，决不遮挡右侧搜索框；   |
|            搭配连续无限循环跑马灯 (Continuous Marquee) 与悬停扩展热区    |
+-------------------------------------------------------------------------+
```

## 6. 核心组件标准实现规约 (Component Standards)

### 6.1 悬浮卡片外框 (`FloatingTranslatorCard`)
- 必须支持全边缘 8 向拉伸把手（`resize-handle`），把手在 Hover 时带有微弱高光；
- 缩放手柄层级限制为 `z-20` 并位于四角最外沿，顶栏所有按钮及控制胶囊强制定义为 `relative z-30` 并配备 `e.stopPropagation()`，彻底杜绝拉手对按钮点击的拦截；
- 拖拽运动位移阈值：必须应用 4px 位移判断（`Math.hypot(dx, dy) >= 4`），原位点击绝不触发 `isDragging` 拖拽状态与阻尼微缩，保障点击精准无延迟；
- 拖拽激活状态下应用 `scale-[1.018]` 阻尼放大，投影从 `shadow-2xl` 渐变为 `shadow-[0_55px_120px_-15px_rgba(0,0,0,0.85)]`，强调景深抬升；
- 卡片关闭与拖拽判定区必须排除内部 `button`、`input` 与 `.no-drag` 元素，防止误触。

### 6.2 语音与复制按钮
- 统一采用圆形微透触控靶标：`p-1 rounded-full text-white/60 hover:text-white hover:bg-white/10 transition-colors`；
- 成功反馈必须伴随明确的微状态变动（如点击复制后变为 `Check` 图标并呈现 `text-emerald-400`，保持 1.8 秒恢复）。

### 6.3 语言选择胶囊 (`LanguageSelector`)
- 触发器外框采用 `bg-white/10 hover:bg-white/15 border border-white/15 rounded-full`；
- 下拉弹窗必须覆盖 `bg-slate-900/95 backdrop-blur-2xl border border-white/20 shadow-2xl`，选中项以 `text-blue-400 font-semibold` 标示。

### 6.4 原地截图卡片 (`InPlaceScreenshotCard`)
- 截图后卡片位置必须**像素级精确锚定在用户所画截图矩形坐标 $(X, Y, W, H)$** 上；
- 背景使用高透明毛玻璃（`bg-slate-950/80 backdrop-blur-2xl`），中英双语严密保持逐行对齐，原行原段原貌呈现。

### 6.5 词汇详情卡片 (`WordDetailView`)
- **顶栏标题行**：大号加粗单词拼写（`font.bold`、`text-white`、`text-xl`）与淡蓝音标（`/ipa/`、`text-blue-300`）自然基线对齐，右侧紧贴美/英（US/UK）发音胶囊；
- **发音胶囊规范**：微型双向圆角矩形，美音以电光蓝（`#60a5fa`）为辅，英音以翡翠绿（`#34d399`）为辅，悬停高亮；
- **词性与多重释义层级**：首要释义配蓝色词性标签高亮显示，次级释义（`definitions.slice(1)`）在下部微光分隔线后轻量排列，词性等宽字体呈现；
- **双向联动**：点击同义词、反义词或历史词条，自动回填至输入框并触发实时翻译。

### 6.6 历史记录与生词本独立窗口 (`HistoryWindow / HistoryDrawer`)
- **层级与形态**：由原侧边全屏阻塞抽屉重构为**独立浮动桌面窗口**（遵循 `设置/截图/历史记录使用独立窗口` 规范）；
- **独立控制与拖拽**：配备标准 macOS 红绿灯操作（红灯关闭、黄灯收缩为常驻生词胶囊、绿灯居右复位），顶部标题栏支持鼠标自由平移；
- **材质与视觉统一**：采用 `bg-slate-900/92 backdrop-blur-3xl border border-white/20 rounded-[26px]`，彻底剔除浅色模式白底反差；
- **实时过滤与操作**：内置即时搜索框与「全部」/「生词本」快速筛选标签，条目悬停具备精致高光动效，支持真人发音与移入/移出生词本；
- **无遮罩多任务**：无全屏变暗遮罩，允许用户在查词、对照或阅读长文时保持生词本侧边并列展示。

### 6.7 截图框选逐行中英对照视图 (`ScreenshotTranslationView`)
- **顶栏控制条**：深色半透明胶囊，包含 Crop 图标、行数统计、语言方向提示与「逐行中英对照」蓝色胶囊徽标，右侧配备「原图缩略图折叠」、「重新截图」与「返回常规翻译」按钮；
- **逐行双语卡片结构**：每一行文本采用独立微透暗调卡片，悬停具备微妙提亮效果；上方为原文（带蓝色圆点、发音朗读与复制），下方为译文（带薄荷绿圆点、发音朗读与独立复制）；
- **底部对照工具栏**：支持「一键复制全部对照」并伴随对勾动画反馈，支持「朗读全部译文」，支持无缝切回文本翻译。

### 6.8 独立偏好设置与多引擎配置窗口 (`SettingsWindow / SettingsModal`)
- **独立窗口形态**：完全脱离全屏遮罩，升级为标准**独立浮动桌面配置窗口**；
- **原生红绿灯与最小化**：支持关闭、最小化为桌面药丸胶囊、居中复位；
- **全系统暗夜冷灰毛玻璃**：统一使用 `bg-slate-900/92 backdrop-blur-3xl border border-white/20 rounded-[26px] shadow-2xl` 与 `inset 0 1px 0 rgba(255, 255, 255, 0.2)` 倒角高光；
- **模块化胶囊导航**：

## 8. Anti-Slop（反套路）禁止清单 (Banned Anti-Patterns)

为确保项目长期的视觉纯度与设计质感，代码审核中若出现以下特征视为**不合格代码**，必须立刻纠正：

1. ❌ **严禁使用廉价的紫蓝大面积高饱和渐变**（例如 `bg-gradient-to-r from-purple-500 to-indigo-500` 作为大卡片背景）；
2. ❌ **严禁嵌套卡片（Cards Inside Cards）**：不要在一个白框卡片里面又套两三个带边框白框卡片，层级必须通过背景明暗微差（5%~10%）、字体大小与细分隔线（`border-white/10`）体现；
3. ❌ **严禁滥用全大写超小间距 Hero 眉题**（如 `TRACKED UPPERCASE EYEBROWS` 充斥全屏）；
4. ❌ **严禁使用粗左侧边框卡片（Left-side thick border）**；
5. ❌ **严禁纯黑纯白生硬碰撞**（禁止 `#000000` 纯黑搭配 `#FFFFFF`，必须使用微暖或微冷带有 3%~5% 色相饱和度的灰阶）；
6. ❌ **严禁图标尺寸不均**（工具栏图标严格限制在 `w-3.5 h-3.5` (14px) 或 `w-4 h-4` (16px)，保持严密网格对齐）。


## 9. 桌面端工具栏即时响应（2026-09-08）

适用范围：Qt/QML 桌面端顶部、底部与共享工具按钮。本节覆盖上述通用动效时长在这些控件中的规定；Web/PWA 未在本轮修改。

- 工具栏宽度、间距和紧凑断点不使用 Behavior 补间，窗口缩放后按当前几何在下一帧布局；“即时”指不额外增加动画等待，不代表测得系统端到端 0ms 延迟。
- 红绿灯占位固定为 48×24，悬停只改变外观。按钮按下的图标反馈立即发生，按钮命中区域不缩放、不移动；颜色回落统一使用 `DesignTokens.toolbarFeedbackMs = 60`。
- 语言与引擎根据可用空间收紧，不再悬停展开挤压相邻按钮。HoverHandler 只观察悬停，具体按钮接收点击。
- 设置入口常驻。极窄窗口下，顶部/底部提供横向滚动条，所有操作可滚动到达，不挤压或裁掉功能；空间足够时不启用滚动交互，顶部空白仍可拖动窗口。
- 底部降低辅助信息优先级：Smart-Select 文字在宽度 ≥360 时显示，语言简标 ≥480，尺寸读数 ≥440；开关及已有翻译结果的操作组保留。开关位置即时更新。
- 顶部拖动区域置于交互内容后方；八向缩放热区限制在外沿（侧边/底边 5px、角部 8px），避免覆盖工具按钮。
- 卡片加载状态绑定 Core 已有的 `isTranslating`，不使用不存在的 `isLoading`。

验证：`python scripts/test_toolbars.py --qt-bin "<Qt安装目录>/bin"`。使用真实 QML 组件及独立状态夹具，覆盖 160/220/260/300/380/480/800 宽度、结果/加载/空状态、按钮点击、即时几何及按下反馈；截图和报告位于 `build/toolbar-check/`。不验证翻译 API、系统输入延迟或所有屏幕 DPI。

参考：[Qt Quick 性能说明](https://doc.qt.io/qt-6/qtquick-performance.html)、[HoverHandler](https://doc.qt.io/qt-6/qml-qtquick-hoverhandler.html)。

启动兼容修复：音乐浮层使用等色（rgba 0.04/0.06/0.12/0.88）、24px 圆角 Rectangle；按钮显式设置 width/height，替代未定义属性，避免整个主界面加载失败。音乐能力未在本轮做业务验证。

极窄工具栏的横向滚动条采用 Qt Quick Controls Basic 的 3px 灰蓝滑块和透明轨道，避免 Windows 原生白色滚动条侵入深色工具栏。


## 10. 窄宽度内容与药丸（2026-09-08）

- 单词与音标各自占一行，允许长内容换行，不能靠超出容器绘制来保全字符串。标题组可收缩至 0 最小宽度；有效宽度小于 `360 × fontScale` 时，美/英发音另起一行。
- 极简卡片的音标前缀与译文使用独立区域：宽度小于 260 且高度够用时上下排列，否则音标最多占 42% 宽度并省略，译文在剩余区域单独裁剪滚动。滚动不得越过音标边界。
- 药丸最小 160×38：保留搜索、发音、更多、展开；宽度 ≥340 时显示复制、截图、音乐，≥440 时显示输入框，≥480 时显示红绿灯。动作组使用真实隐式宽度，不允许固定宽度小于所有按钮之和。
- “更多”使用紧贴内容的独立菜单窗口（Popup.Window），避免超出药丸主窗口后被裁切。搜索缩为图标时点击展开卡片；按钮无悬停几何膨胀。38 高度下按钮保持 28 高度且在窗口内部。
- 四边与四角使用可中断缩放；待提交帧期间合并为最新指针位置，松手/取消必须清理状态。Windows 对侧保持物理像素锚定，圆角由 Rectangle 自身抗锯齿，不启用整窗 4× MSAA。定时器及 frameSwapped 都不代表桌面已经显示该帧。

验证脚本见 `tests/qml/tst_narrow.qml` 与 `scripts/probe_native_resize.py`。原生探针依赖 Windows、Python 和 Pillow，会操作指定 PID 的窗口和鼠标，并临时显示纯色背景；只在主动验证时运行。屏幕采样不等同于逐帧高速录像。

## 11. 大圆角边界（2026-09-08）

**当前正式版**沿用用户验收的测试框 GDI+ 圆弧端点、抗锯齿和内描边，取代下面历史阶段的 QPainter 外壳。主卡片采用 48px 顶栏和 44px 底栏，低于 160px 高度时采用 32px 顶栏与简洁结果区。按钮固定占位，更多操作为独立窗口；文字大小 70%–150%，单词/音标/发音独立布局。主模式只由宿主改变尺寸，无第二套内容整体缩放动画。

正式主窗口外壳按物理像素绘制：卡片半径为 round(32 × DPI倍率)，药丸半径为物理高度一半，均不超过短边一半；描边为 round(DPI倍率) 且至少 1px。内容由同一轮廓遮罩限制，不允许内部矩形露出圆角。QML GlassSurface 作为独立预览回退；颜色和透明度由 Main.qml 传递主题值。

可见性验收必须覆盖启动首帧、静止后续帧和实际桌面截图。进程 Responding、窗口坐标正常或提交函数成功均不能单独作为界面已显示的证据。背景与控件的未变化像素必须在增量刷新时保留。

2026-09-09 起，主窗口的 32px 卡片圆角和半高药丸圆角先在离屏 ARGB 帧中完整绘制，再与目标物理尺寸一次提交。缩放过程不改变圆角值，不允许用临时放大半径掩盖旧帧拉伸。界面组件仍使用同一 GlassSurface 轮廓，软件后端不支持的 ShaderEffect 不得加入主窗口。

卡片静止、按下、拉伸、松手均保持 32 逻辑像素大圆角，禁止交互态改变半径做补偿；药丸始终为半高圆角，实际半径不超过宽高的一半。背景底色、柔和纵向高光、细描边均填满同一尺寸、共享同一半径，开启抗锯齿。底栏不再绘制矩形底色。禁止用超出轮廓的大柔光或短条圆角矩形叠加模拟边缘；Item.clip 只提供矩形裁剪，不能作为圆角遮罩。不用 SetWindowRgn，不增加透明外边距。四角缩放热区位于半径 26–32px 的可见圆弧带，避免遮挡内侧按钮。

### 药丸扩展内容

- 药丸原生窗口始终只绘制自身 46px 高度内的内容；音乐详情使用 `360 × 300` 的独立紧凑窗口。
- 禁止把展开面板锚定到药丸窗口边界之外，否则分层窗口离屏画布会将它裁切，造成歌词、进度或控制区显示不全。
- 主界面首帧直接显示，避免长时间入场缩放延迟鼠标反馈。

整体质感采用静态深色玻璃、柔和顶光和单层细描边，减少游动光斑带来的边界变化及重绘。32px 是当前卡片圆弧设计，不宣称与 Apple 连续曲率数学曲线完全相同。

测试：QML 检查覆盖完整卡片七种宽度、160×95 等最小尺寸、药丸背景及按下/松手轮廓不变。QtTest 截图是合成后的 RGB，因此检查曲线外像素与白色测试背景一致，并留出抗锯齿带；不是读取 alpha 通道。原生八向验证使用 `scripts/probe_resize_stability.py`，从同一截图获取可见边界和曲线，双向检查曲线变化；旧 `probe_corner_continuity.py` 的异步混合采样及单侧判定不作为验收证据。

`scripts/probe_all_edges.py --pid <运行进程ID> --output build/toolbar-check/all-edges.json` 在 125% DPI 上分别拖动四边并采样画面，会临时显示纯色背景、操作鼠标，结束恢复正常卡片尺寸。背景显式 UpdateWindow 后取实测底色。对侧坐标稳定不等同于端到端无延迟；截图采样仍可能漏掉亚帧闪动。

`scripts/probe_corner_continuity.py --pid <运行进程ID> --output build/toolbar-check/corner-continuity.json` 快速向内缩小右边和底边，测量两个相邻圆角在 2px 切线处的背景切入深度。允许抗锯齿产生最多 2 逻辑像素变化；结果小于静止基线减去该容差即判定圆弧被压扁。
