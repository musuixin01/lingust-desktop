# Linguist 视觉设计规范与 UI 系统指南 (Design System & Style Guide)

> 验证状态与真实环境边界见 [全局功能验证记录](./VALIDATION.md)。

> **版本**：v1.2.0  
> **状态**：项目强制执行标准 (Mandatory Engineering Standard)  
> **适用范围**：所有前端组件、悬浮卡片、弹窗模态、原子控件及未来扩展视图

设置页账户区域使用单层 16px 连续圆角玻璃卡片：默认只显示账户摘要和“登录 / 注册”，点击后在原位置展开，不创建额外登录窗口。登录/注册与邮箱/手机号均使用双选分段控件；字段高度 38px、主要按钮 39px，错误紧邻字段或操作区显示。允许粘贴密码与验证码，Tab/回车可完成操作；按下只改变材质颜色，不移动布局。微信入口使用同一套线性 SVG 图标并交给系统浏览器。

## 1. 设计哲学与核心基调 (Design Philosophy)

Linguist 是一款面向现代化桌面场景的高端生产力翻译与词典工具。其视觉语言的核心在于**“极简、克制、沉浸与高度聚焦”**：

- **桌面级毛玻璃拟物美学 (Frosted Glassmorphism)**：借鉴 macOS 原生层级与半透明磨砂质感，让应用悬浮在任意桌面背景、IDE 或阅读器之上时，既能清晰分离层次，又能自然融入宿主环境。
- **内容绝对第一 (Content-First & Optical Purpose)**：杜绝华而不实的装饰性花哨元素。每一个内边距、每一处微阴影、每一个字号阶梯都必须有明确的光学对齐与功能目的。
- **自适应几何连续性 (Adaptive Geometric Continuity)**：从大尺寸的多功能词典卡片，到极小尺寸的极简双行翻译，再到极薄的桌面悬浮药丸，卡片形态变化平滑，视觉权重自洽。
- **Anti-Slop（反 AI 套路）铁律**：严禁滥用大面积高饱和紫蓝渐变、禁止无意义的高光发光外阴影、严禁随意嵌套卡片（Cards inside cards），保持高级冷灰暗调与微光漫反射质感。

## 2. 色彩系统与色彩语义 Token (Color Palette & Tokens)

项目默认采用**深空微蓝冷调暗夜主题 (Deep Midnight Space)**，所有半透明材质基于白色漫反射光（White Alpha）与深色环境遮罩（Dark Alpha）构建。

### 2.1 基础材质与表面 Token (Surfaces & Glass Layers)

| Token 变量 / 类名 | 颜色值 / CSS 属性 | 适用层级与场景 |
| :--- | :--- | :--- |
| **画布底层背景** (`.frosted-glass-canvas`) | `#0a0a1a` 配合两处微弱的径向暗紫/洋红漫反射光晕 | 桌面仿真底层背景 |
| **主悬浮卡片背景** (`bg-white/10`) | `rgba(255, 255, 255, 0.10)` | 核心悬浮卡片、截图原地卡片 |
| **次级容器背景** (`bg-white/5`) | `rgba(255, 255, 255, 0.05)` | 语言选择胶囊、词性释义块、输入框外壳 |
| **深色悬浮抽屉** (`bg-slate-900/95` 或 `bg-[#0c0d14]`) | `rgba(12, 13, 20, 0.95)` | 设置模态弹窗、生词本抽屉、悬停多行展开浮层 |
| **模糊滤镜强度** (`backdrop-blur-3xl`) | `blur(40px)` 或 `-webkit-backdrop-filter: blur(40px)` | 悬浮卡片高斯模糊核心参数 |
| **微光外边框** (`border-white/20`) | `1px solid rgba(255, 255, 255, 0.20)` | 静止态卡片与容器边界 |
| **激活高亮边框** (`border-white/35`) | `1px solid rgba(255, 255, 255, 0.35)` | 拖拽中、获取焦点中、激活选态 |
| **内表面高光刻痕 (Specular)** | `inset 0 1px 0 rgba(255, 255, 255, 0.25)` | 为卡片顶部提供 macOS 般精细的物理倒角反光 |

### 2.2 文本与层级对比度 Token (Typography Colors)

项目严格保证 WCAG AA（对比度大于 4.5:1）的可读性规范，严禁在彩色背景上使用不可读的暗灰文字：

| 文本层级 | Tailwind Token | 不透明度 | 推荐使用场景 |
| :--- | :--- | :--- | :--- |
| **主要强调文本** | `text-white` | 100% | 单词拼写、翻译核心译文、标题、当前激活项 |
| **正文次要文本** | `text-white/85` ~ `text-white/90` | 85% ~ 90% | 词性中文释义、双语例句译文、输入框输入文字 |
| **辅助弱化文本** | `text-white/60` ~ `text-white/70` | 60% ~ 70% | 音标 IPA、双语例句英文原文、同反义词标签 |
| **占位与失效文本** | `text-white/35` ~ `text-white/40` | 35% ~ 40% | Input Placeholder、快捷键提示、清空按钮默认态 |

### 2.3 语义与功能强调色 Token (Semantic Colors)

| 功能语义 | 色值 Token | 实际应用场景 |
| :--- | :--- | :--- |
| **苹果红绿灯 (关闭/清空)** | `bg-red-400/80` (Hover: `bg-red-400`) | 标题栏红色按钮、删除生词本记录 |
| **苹果红绿灯 (最小化/药丸)** | `bg-amber-400/80` (Hover: `bg-amber-400`) | 标题栏黄色按钮、警告提示、生词收藏高光 |
| **苹果红绿灯 (刷新/成功)** | `bg-emerald-400/80` (Hover: `bg-emerald-400`) | 标题栏绿色按钮、复制成功勾选、连通测试通过 |
| **主要交互强调蓝 (Primary Accent)** | `text-blue-400`, `bg-blue-500` | 截图按钮、语言选择激活底色、聚焦外轮廓环光 |
| **高级紫色辅色 (Purple)** | `text-purple-400`, `bg-purple-500/20` | 双语例句标识、AI 语境模式标识 |

## 3. 排版与字体阶梯系统 (Typography System)

### 3.1 字体家族配比原则
1. **界面主无衬线体 (Sans-serif)**：
   - Windows 桌面统一使用系统自带 `Microsoft YaHei UI`，覆盖简体中文、拉丁字母和常用符号；禁止运行时下载字体，避免首屏延迟与字形切换。
   - 适用于：标题、按钮文字、翻译主结果、控制栏。
2. **音标与数字等宽体 (Monospace)**：
   - Windows 桌面调用系统自带 `Cascadia Mono`；只用于音标、快捷键、百分比和时间等窄范围信息。
   - 适用于：音标 `/[ˈlɪŋɡwɪst]/`、快捷键指示符、时间戳。
3. **典范双语例句衬线体 (Serif)**：
   - 双语例句与英文释义使用 `Microsoft YaHei UI`，保证中英文混排字面、基线与字号稳定一致。

### 3.2 字号与行距阶梯 (Scale & Line Height)

| 尺寸等级 | 字号 / 行高 | 适用元素 |
| :--- | :--- | :--- |
| **2XS** | `text-[9px]` ~ `text-[10px]` / `leading-none` | 紧凑模式音标、标签徽章、微型发音指示 |
| **XS** | `text-xs` (11~12px) / `leading-snug` | 紧凑例句、控制栏图标说明、辅助释义 |
| **SM** | `text-sm` (13~14px) / `leading-snug` | 搜索框输入文字、紧凑卡片翻译译文、释义主体 |
| **BASE** | `text-base` (15~16px) / `leading-tight` | 紧凑单词详情词条、模态窗主标题 |
| **LG** | `text-lg` (18px) ~ `text-xl` (20px) | 标准卡片大词条、极简模式放大的主译文 |

### 3.3 动态字号微调与输入规范 (Custom Font Sizing)
- **默认精致基准**：默认字号比例设为 `92%`（`customFontSize: 92`），使文本与界面在紧凑状态下自然呼吸，解决卡片偏小而字体显过大的失调问题；
- **全范围自由数值输入**：支持在 `60%` ~ `150%` 之间直接输入任意数字调节字号，并由 `effectiveFontScale = (customFontSize / 100) * fluidScale` 结合容器几何长宽平滑缩放；
- **行高与外边距数学收敛**：在动态紧凑模式（`isDynamicCompact`）下，全局行高严禁使用松散的 `leading-relaxed`，一律收窄为 `leading-tight` / `leading-snug`，行间距压缩为 `space-y-1.5` ~ `space-y-2`，外边距从 `p-4.5` 压缩至 `p-2.5`，确保内容区域即使被裁切也能完整阅读。

### 3.4 溢出排版与悬停跑马灯 (Hover-Scroll) 规范
- **禁止断行与硬截断**：按钮、Tab 标签、音标药丸内文字严禁换行、折字；
- **单行超出处理**：
  - 普通元素采用 `truncate`（`overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`）；
  - 核心翻译与输入框使用专用 `HoverScrollText` 组件：鼠标悬停时平滑双向来回滚动，速度固定为 `35px/s`，两端停顿 `600ms`，左右两端附加渐变遮罩 (`mask-pill-marquee`)。

## 4. 间距、栅格与圆角数学规约 (Spacing & Corner Math)

### 4.1 8pt 基础间距模数
项目全局基于 4px / 8px 的倍数步进：
- 极微间距：`gap-1` (4px), `gap-1.5` (6px)
- 标准间距：`gap-2` (8px), `gap-3` (12px), `gap-4` (16px)
- 区域段落间距：`p-3` (12px), `p-4` (16px), `p-6` (24px)
- **容器与按钮边距法则**：按钮水平内边距必须严格为垂直内边距的 2 倍（例如：`px-3 py-1.5` 或 `px-4 py-2`）。

### 4.2 圆角数学嵌套定律 (Nested Corner Radius Math)
**严禁随意拍脑袋设定圆角**。当一个圆角容器嵌套在另一个圆角容器内部时，内圆角半径必须满足：
$$\text{Inner Radius} = \text{Outer Radius} - \text{Padding}$$

#### 项目具体落地参数：
- **完整主卡片 (Outer Card)**：
  - 外层容器：`rounded-[32px]` (32px)
  - 容器内边距：`p-3` (12px)
  - 内部输入容器与词条区域：`rounded-[20px]` (32px - 12px = 20px)
- **极简模式卡片 (Minimal Card)**：
  - 外层容器：`rounded-2xl` (16px)
  - 内边距：`p-2` (8px)
  - 内部文本块：`rounded-lg` (8px)
- **药丸模式 (Pill Mode)**：
  - 全封闭半圆：`rounded-full` (9999px)
  - 内部搜索输入与按钮：`rounded-full`

## 5. 卡片几何多态断点系统 (Adaptive Geometry Breakpoints)

主悬浮卡片通过实时监测容器尺寸 ($W \times H$)，在不同几何边界下动态切换 UI 视觉策略：

```
+-------------------------------------------------------------------------+
| 1. 标准展开态 (Standard Mode)                                            |
|    - 边界: W >= 340px 且 H >= 240px                                     |
|    - 特征: 完整展示红绿灯、拖拽控制栏、语言选择器、音标发音、多词性释义、  |
|            双语例句、同义词标签与底部状态栏                             |
+-------------------------------------------------------------------------+
                                    │ 缩窄或收敛高度
                                    ▼
+-------------------------------------------------------------------------+
| 2. 紧凑模式与流式缩放 (Compact Mode & Fluid Scale)                     |
|    - 边界: W < 420px 或 H < 400px 或 settings.compactMode 开启           |
|    - 特征: 【内容绝对一致性】卡片变小过程中绝不删减任何核心释义、例句与同反义词；|
|            【流式等比自适应】采用数学因子 fluidScale 进行字号与内边距紧凑化压缩； |
|            【紧凑排版微调】外边距 p-2.5，间距 space-y-2，行高 leading-snug；     |
|            【字号自由微调】顶栏与设置项均支持直接键盘输入 60%~150% 任意字号；     |
|            【控件永久保留】红绿灯、引擎指示器、截图、固定、设置、复制及朗读永不消失 |
+-------------------------------------------------------------------------+
                                    │ 进一步极小化拉伸
                                    ▼
+-------------------------------------------------------------------------+
| 3. 极小极简模式 (Minimal Mode)                                          |
|    - 边界: H <= 145px 或 (W <= 240px 且 H <= 190px)                     |
|    - 特征: 【核心视觉保留】仅保留搜索输入框与译文结果；                  |
|            【色彩绝对统一】译文颜色严格统一为标准强调色 text-white/95，禁止绿色； |
|            【角落微感应浮动】严禁整条顶部感应，仅当光标进入最左上角或最右上角微型 |
|                              热区 (w-9 h-7，即 36px×28px) 时才弹出独立控制胶囊；  |
|            【溢出滚动保障】内容超出时支持 HoverScroll 悬停双向平滑滚动   |
+-------------------------------------------------------------------------+
                                    │ 点击黄色按钮或最小化
                                    ▼
+-------------------------------------------------------------------------+
| 4. 桌面胶囊药丸 (Pill Mode)                                             |
|    - 边界: 手动点击最小化 或 高度 <= 48px                               |
|    - 特征: 38px~60px 超薄高透药丸，支持向上收缩高度，向下大幅度展开；    |
|            【防误触发卡片】上推缩小时高度可低至 38px，向下位移 >85px 才展开回卡片；|
|            【放大按钮可靠性】最右侧放大及功能按钮位于 z-50 顶层，阻止事件冒泡；   |
|            【超窄药丸点击保障】即使药丸拉至极小 (<280px)，搜索图标始终保留 28px   |
|                                独立胶囊靶心，点击聚焦瞬间平滑展开为输入框；      |
|            【左侧收缩规避】左侧红绿灯感应区收缩至边缘 16px，决不遮挡右侧搜索框；   |
|            搭配连续无限循环跑马灯 (Continuous Marquee) 与悬停扩展热区    |
+-------------------------------------------------------------------------+
```

## 6. 核心组件标准实现规约 (Component Standards)

### 6.1 悬浮卡片外框 (`FloatingTranslatorCard`)
- 必须支持全边缘 8 向拉伸把手（`resize-handle`），把手在 Hover 时带有微弱高光；
- 缩放手柄层级限制为 `z-20` 并位于四角最外沿，顶栏所有按钮及控制胶囊强制定义为 `relative z-30` 并配备 `e.stopPropagation()`，彻底杜绝拉手对按钮点击的拦截；
- 拖拽运动位移阈值：必须应用 4px 位移判断（`Math.hypot(dx, dy) >= 4`），原位点击绝不触发 `isDragging` 拖拽状态与阻尼微缩，保障点击精准无延迟；
- 拖拽激活状态下应用 `scale-[1.018]` 阻尼放大，投影从 `shadow-2xl` 渐变为 `shadow-[0_55px_120px_-15px_rgba(0,0,0,0.85)]`，强调景深抬升；
- 卡片关闭与拖拽判定区必须排除内部 `button`、`input` 与 `.no-drag` 元素，防止误触。

### 6.2 语音与复制按钮
- 统一采用圆形微透触控靶标：`p-1 rounded-full text-white/60 hover:text-white hover:bg-white/10 transition-colors`；
- 成功反馈必须伴随明确的微状态变动（如点击复制后变为 `Check` 图标并呈现 `text-emerald-400`，保持 1.8 秒恢复）。

### 6.3 语言选择胶囊 (`LanguageSelector`)
- 触发器外框采用 `bg-white/10 hover:bg-white/15 border border-white/15 rounded-full`；
- 下拉弹窗必须覆盖 `bg-slate-900/95 backdrop-blur-2xl border border-white/20 shadow-2xl`，选中项以 `text-blue-400 font-semibold` 标示。

### 6.4 原地截图卡片 (`InPlaceScreenshotCard`)
- 截图后卡片位置必须**像素级精确锚定在用户所画截图矩形坐标 $(X, Y, W, H)$** 上；
- 背景使用高透明毛玻璃（`bg-slate-950/80 backdrop-blur-2xl`），中英双语严密保持逐行对齐，原行原段原貌呈现。

### 6.5 词汇详情卡片 (`WordDetailView`)
- **顶栏标题行**：大号加粗单词拼写（`font.bold`、`text-white`、`text-xl`）与淡蓝音标（`/ipa/`、`text-blue-300`）自然基线对齐，右侧紧贴美/英（US/UK）发音胶囊；
- **发音胶囊规范**：微型双向圆角矩形，美音以电光蓝（`#60a5fa`）为辅，英音以翡翠绿（`#34d399`）为辅，悬停高亮；
- **词性与多重释义层级**：首要释义配蓝色词性标签高亮显示，次级释义（`definitions.slice(1)`）在下部微光分隔线后轻量排列，词性等宽字体呈现；
- **双向联动**：点击同义词、反义词或历史词条，自动回填至输入框并触发实时翻译。

### 6.6 历史记录与生词本独立窗口 (`HistoryWindow / HistoryDrawer`)
- **层级与形态**：由原侧边全屏阻塞抽屉重构为**独立浮动桌面窗口**（遵循 `设置/截图/历史记录使用独立窗口` 规范）；
- **独立控制与拖拽**：配备标准 macOS 红绿灯操作（红灯关闭、黄灯收缩为常驻生词胶囊、绿灯居右复位），顶部标题栏支持鼠标自由平移；
- **材质与视觉统一**：采用 `bg-slate-900/92 backdrop-blur-3xl border border-white/20 rounded-[26px]`，彻底剔除浅色模式白底反差；
- **实时过滤与操作**：内置即时搜索框与「全部」/「截图」/「生词本」快速筛选标签；截图项保留类型标识，点击后回到主卡片的逐行双语对照，普通词条继续支持发音与再次翻译；
- **无遮罩多任务**：无全屏变暗遮罩，允许用户在查词、对照或阅读长文时保持生词本侧边并列展示。

### 6.7 截图框选逐行中英对照视图 (`ScreenshotTranslationView`)
- **顶栏控制条**：深色半透明胶囊，包含 Crop 图标、行数统计、语言方向提示与「逐行中英对照」蓝色胶囊徽标，右侧配备「原图缩略图折叠」、「重新截图」与「返回常规翻译」按钮；
- **逐行双语卡片结构**：每一行文本采用独立微透暗调卡片，悬停具备微妙提亮效果；上方为原文（带蓝色圆点、发音朗读与复制），下方为译文（带薄荷绿圆点、发音朗读与独立复制）；

## 8. Anti-Slop（反套路）禁止清单 (Banned Anti-Patterns)

为确保项目长期的视觉纯度与设计质感，代码审核中若出现以下特征视为**不合格代码**，必须立刻纠正：

1. ❌ **严禁使用廉价的紫蓝大面积高饱和渐变**（例如 `bg-gradient-to-r from-purple-500 to-indigo-500` 作为大卡片背景）；
2. ❌ **严禁嵌套卡片（Cards Inside Cards）**：不要在一个白框卡片里面又套两三个带边框白框卡片，层级必须通过背景明暗微差（5%~10%）、字体大小与细分隔线（`border-white/10`）体现；
3. ❌ **严禁滥用全大写超小间距 Hero 眉题**（如 `TRACKED UPPERCASE EYEBROWS` 充斥全屏）；
4. ❌ **严禁使用粗左侧边框卡片（Left-side thick border）**；
5. ❌ **严禁纯黑纯白生硬碰撞**（禁止 `#000000` 纯黑搭配 `#FFFFFF`，必须使用微暖或微冷带有 3%~5% 色相饱和度的灰阶）；
6. ❌ **严禁图标尺寸不均**（工具栏图标严格限制在 `w-3.5 h-3.5` (14px) 或 `w-4 h-4` (16px)，保持严密网格对齐）。


## 9. 桌面端工具栏即时响应（2026-09-08）

适用范围：Qt/QML 桌面端顶部、底部与共享工具按钮。本节覆盖上述通用动效时长在这些控件中的规定；Web/PWA 未在本轮修改。

- 工具栏宽度、间距和紧凑断点不使用 Behavior 补间，窗口缩放后按当前几何在下一帧布局；“即时”指不额外增加动画等待，不代表测得系统端到端 0ms 延迟。
- 卡片红绿灯占位固定为 48×24；药丸红绿灯静止为 34×18，悬浮恢复 44×22，正文同步让出外框新增的宽度。按钮按下的图标反馈立即发生，颜色回落统一使用 `DesignTokens.toolbarFeedbackMs`。
- 语言与引擎根据可用空间收紧，不再悬停展开挤压相邻按钮。HoverHandler 只观察悬停，具体按钮接收点击。
- 设置入口常驻。极窄窗口下，顶部/底部提供横向滚动条，所有操作可滚动到达，不挤压或裁掉功能；空间足够时不启用滚动交互，顶部空白仍可拖动窗口。
- 底部降低辅助信息优先级：Smart-Select 文字在宽度 ≥360 时显示，语言简标 ≥480，尺寸读数 ≥440；开关及已有翻译结果的操作组保留。开关位置即时更新。
- 顶部拖动区域置于交互内容后方；八向缩放热区限制在外沿（侧边/底边 5px、角部 8px），避免覆盖工具按钮。
- 卡片加载状态绑定 Core 已有的 `isTranslating`，不使用不存在的 `isLoading`。

## 10. 窄宽度内容与药丸（2026-09-08）

- 词头按内容宽度自适应：单词、音标与美/英发音的自然宽度总和能够放入内容区时，三者紧凑排列在同一行；空间不足时才分别换行。长内容允许安全断行，不能靠超出容器绘制来保全字符串。
- 极简卡片的音标前缀与译文使用独立区域：宽度小于 260 且高度够用时上下排列，否则音标最多占 42% 宽度并省略，译文在剩余区域单独裁剪滚动。滚动不得越过音标边界。
- 药丸支持 160px 起的水平缩放和 38–72px 的高度缩放。普通药丸的红绿灯外框静止为 34×18px、圆点为 7px；悬浮后外框以 150ms 放大到 44×22px，圆点同步增至 9px，正文按外框当前宽度连续让位。宽度 ≤220px 时整组默认隐藏，鼠标进入最左侧 10px 感应区后显示。
- 药丸的空间优先级为“核心译文 → 当前单词 → 右侧功能”。搜索词和核心译文都使用当前字体做实际宽度测量；右侧操作只使用剩余空间并从左侧逐项收起，不允许出现半颗按钮。不同单词和译文在同一窗口宽度下可以得到不同的按钮数量。
- 六项操作采用 23px 紧凑圆形和 1px 间距，总宽 143px，固定在距窗口右侧 10px 的位置。只有存在隐藏操作时，最右边缘才允许触发完整展开；展开时搜索框退出布局，普通宽度红绿灯保留，译文使用剩余宽度且不得与操作重叠。移出操作区 90ms 后恢复内容优先布局，窗口宽度变化会解除旧悬浮状态。
- 药丸搜索入口默认是 26px 高的小药丸，最小宽度状态从窗口左侧 22px 开始，和 16px 红绿灯感应区至少保留 6px 间距。空入口使用冷蓝透明底、内层纵向渐变高光、低透明细描边与居中搜索图标，形成克制的液态玻璃按钮；悬浮不改变尺寸也不显示编辑器。已有文字后，静止宽度按照原词实际宽度在 46–108px 内分配，能容纳时完整显示，超过上限时只滚动文字。点击后在药丸内部以最少 64px 编辑并随输入长度增长至最多 108px，不切换窗口模式；Escape、点击窗口其他区域、切换到其他应用或清空文字后收回搜索。
- 搜索使用轻触手势进入编辑，禁止在输入框上叠放抢焦点的点击层。翻译完成后，若鼠标已经离开整个药丸，搜索编辑自动收起；若鼠标仍在药丸上则保持当前编辑状态，避免结果返回时打断用户。
- 药丸结果只显示首条词典释义中的核心义项；词性以前缀形式使用强调蓝，释义使用主文本色。完整多词性内容继续由卡片承载，避免药丸中的次要含义挤压常用操作。
- 药丸等待翻译时不显示状态文字，使用 5px 蓝、紫、绿色三点波浪动画表示请求仍在执行；动画只占译文区域且结果到达后立即停止。右侧操作展开不再隐藏普通宽度药丸的红绿灯，内容根据红绿灯实际右边缘重新分配。
- 图标按下立即缩至 94%，松开后以 130ms 回弹并显示 280ms 蓝色执行环。执行环表示点击已被应用接收；复制按钮同时绑定 `justCopied` 业务状态。无法执行的复制与朗读按钮使用禁用态，不显示虚假的成功反馈。
- 译文跑马灯只响应译文区域自身的悬浮。溢出文本在悬浮 300ms 后以恒定速度滚动，鼠标移出时立即停止并回到起点；悬浮搜索、按钮、红绿灯或窗口空白不得启动译文滚动。
- 右侧完整展开的感应区覆盖窗口最右 32px 并贴合真实边界，仅在 `normalActionCount < 6` 时存在。六项功能齐全时该感应区禁用；有隐藏项时从真实最右边缘进入即可展开，操作区自身负责保持展开，移出后延迟 90ms 收回。
- 药丸红绿灯外框和内部圆点使用同一悬浮状态：外框从 34×18px 放大到 44×22px，圆点从 7px 放大到 9px，间距从 3px 增至 4px；相邻内容根据外框实际右边缘连续让位，所有补间均可被新的指针状态中断。
- 分层窗口必须把原生鼠标离开事件转交 QML。鼠标离开整个窗口时，搜索预览、译文跑马灯、右侧展开和红绿灯悬浮状态应在同一交互周期结束，不得依赖下一次进入窗口的鼠标移动来复位。
- 原生移动事件先更新离屏 QML 的按钮与悬浮处理器，再用窗口实际局部坐标最终确认边缘状态。存在隐藏操作时最右 32px 为完整操作展开区；宽度 ≤220px 时最左 16px 为红绿灯揭示区。两者覆盖 10px 缩放命中带，即使边缘显示缩放光标也不得丢失悬浮反馈。
- 药丸维护独立的窗口级 `pointerInsideWindow` 状态。原生离开事件将其设为 false，并作为搜索词、译文跑马灯和红绿灯悬浮效果的总开关；再次收到窗口内移动后恢复。搜索首次进入编辑时全选现有原词，让用户直接覆盖输入。
- 卡片与药丸的四边、四角都使用可中断缩放；待提交帧期间合并为最新指针位置，松手/取消必须清理状态。Windows 对侧保持物理像素锚定；缩放期间关闭工具组宽度补间，直接按当前几何布局，避免控件滞后造成重叠。定时器及 frameSwapped 都不代表桌面已经显示该帧。

验证脚本见 `tests/qml/tst_narrow.qml` 与 `scripts/probe_native_resize.py`。原生探针依赖 Windows、Python 和 Pillow，会操作指定 PID 的窗口和鼠标，并临时显示纯色背景；只在主动验证时运行。屏幕采样不等同于逐帧高速录像。

## 11. 大圆角边界（2026-09-08）

**当前正式版**保留用户验收测试框的原生 GDI+ 整帧提交、物理像素对齐、抗锯齿和内描边；卡片轮廓升级为 2.6 阶连续曲率曲线，药丸继续使用标准半圆胶囊。主卡片采用 48px 顶栏和 44px 底栏，低于 160px 高度时采用 32px 顶栏与简洁结果区。按钮固定占位；文字大小 70%–150%，单词/音标/发音独立布局。主模式由宿主改变尺寸，药丸与卡片仅做短交叉淡入，不叠加整体缩放。

正式主窗口外壳按物理像素绘制：卡片半径为 round(32 × DPI倍率)，药丸半径为物理高度一半，均不超过短边一半；描边为 round(DPI倍率) 且至少 1px。内容由同一轮廓遮罩限制，不允许内部矩形露出圆角。QML GlassSurface 作为独立预览回退；颜色和透明度由 Main.qml 传递主题值。

可见性验收必须覆盖启动首帧、静止后续帧和实际桌面截图。进程 Responding、窗口坐标正常或提交函数成功均不能单独作为界面已显示的证据。背景与控件的未变化像素必须在增量刷新时保留。

2026-09-09 起，主窗口的 32px 卡片圆角和半高药丸圆角先在离屏 ARGB 帧中完整绘制，再与目标物理尺寸一次提交。卡片缩放保持 32px 圆角，药丸随当前高度保持半高圆角；不允许用临时放大半径掩盖旧帧拉伸。界面组件仍使用同一 GlassSurface 轮廓，软件后端不支持的 ShaderEffect 不得加入主窗口。

卡片静止、按下、拉伸、松手均保持 32 逻辑像素大圆角，禁止交互态改变半径做补偿；药丸始终为半高圆角，实际半径不超过宽高的一半。背景底色、柔和纵向高光、细描边均填满同一尺寸、共享同一半径，开启抗锯齿。底栏不再绘制矩形底色。禁止用超出轮廓的大柔光或短条圆角矩形叠加模拟边缘；Item.clip 只提供矩形裁剪，不能作为圆角遮罩。不用 SetWindowRgn，不增加透明外边距。四角缩放热区位于半径 26–32px 的可见圆弧带，避免遮挡内侧按钮。

### 药丸扩展内容

- 药丸原生窗口始终只绘制自身 46px 高度内的内容；音乐详情使用 `360 × 300` 的独立紧凑窗口。
- 禁止把展开面板锚定到药丸窗口边界之外，否则分层窗口离屏画布会将它裁切，造成歌词、进度或控制区显示不全。
- 主界面首帧直接显示，避免长时间入场缩放延迟鼠标反馈。

整体质感采用静态深色玻璃、柔和顶光和单层细描边，减少游动光斑带来的边界变化及重绘。卡片的 32px 设计半径以 2.6 阶超椭圆生成连续肩部，在保持明显大圆角的同时消除直线接入圆弧时的曲率突变；每个角在直线与转角附近加密采样，四角共用严格镜像的点序列。底色、内容裁剪、静态细边框、流光距离场与缩放反馈必须使用同一轮廓参数，禁止因各层曲线不同而露出方角或产生光边错位。

测试：QML 检查覆盖完整卡片七种宽度、160×95 等最小尺寸、药丸背景及按下/松手轮廓不变。QtTest 截图是合成后的 RGB，因此检查曲线外像素与白色测试背景一致，并留出抗锯齿带；不是读取 alpha 通道。原生八向验证使用 `scripts/probe_resize_stability.py`，从同一截图获取可见边界和曲线，双向检查曲线变化；旧 `probe_corner_continuity.py` 的异步混合采样及单侧判定不作为验收证据。

`scripts/probe_all_edges.py --pid <运行进程ID> --output build/toolbar-check/all-edges.json` 在 125% DPI 上分别拖动四边并采样画面，会临时显示纯色背景、操作鼠标，结束恢复正常卡片尺寸。背景显式 UpdateWindow 后取实测底色。对侧坐标稳定不等同于端到端无延迟；截图采样仍可能漏掉亚帧闪动。

`scripts/probe_corner_continuity.py --pid <运行进程ID> --output build/toolbar-check/corner-continuity.json` 快速向内缩小右边和底边，测量两个相邻圆角在 2px 切线处的背景切入深度。允许抗锯齿产生最多 2 逻辑像素变化；结果小于静止基线减去该容差即判定圆弧被压扁。

## 12. Web 与桌面主题统一（2026-09-10）

- Web 端 `FloatingTranslatorCard` 是主卡片与药丸的视觉结构基准：深色玻璃表面、白色低透明边框、蓝色翻译强调、绿色音乐状态、琥珀色收藏状态。
- 原生外壳在底色上叠加一层从冷白到淡蓝的低透明纵向高光，模拟玻璃随曲面聚光的层次；只用于顶层窗口与控制层，不在正文内部重复嵌套玻璃。该实现不宣称提供 macOS 原生折射，仅在 Windows 分层窗口能力内保持清晰、轻盈和连续形变。
- 桌面卡片顶部顺序固定为红绿灯、语言/引擎、截图/置顶/音乐/设置。设置是最右端常驻入口，不再使用“快捷操作”中转窗口。
- 设置、历史、音乐、截图统一采用 `windowSurface`、`windowHeader`、`radiusWindow = 26` 和 `borderNormal`。页面不得自行引入另一套背景色或圆角。
- 控件按下反馈立即发生，短反馈为 110ms；常规状态过渡为 180ms；工具窗口打开使用 160ms 淡入与轻微缩放，关闭为 100ms。动画只改变透明度和缩放，不推动相邻布局。
- 主卡片与药丸切换由原生宿主以顶部水平中心为锚点改变尺寸：展开 200ms、收起约 170ms，使用 `OutCubic`，反向操作从当前帧继续。两套内容在 130–160ms 内交叉淡入且只有当前模式接收输入；不叠加 QML 整体缩放。原生圆角按当前高度在半高胶囊与 32 逻辑像素间连续收敛。滚动区域使用 `StopAtBounds`，不增加弹簧回弹造成的边界漂移。

### 卡片顶部与底部的兼容布局

- 卡片与药丸共享同一个原文状态。划词到达后，两处搜索框必须在译文返回前立即显示原文；清空任一搜索框会同步清除整组翻译结果。药丸原文为空时搜索入口收回 26px，使用 150ms `OutCubic`，不保留空白编辑框。
- 卡片清空原文后恢复 220×200px 初始尺寸，宽度与高度使用同一个 180ms `OutCubic` 动画；之前由用户拉伸保存的卡片宽度同时清除，避免空状态留下无意义的大面积留白。卡片和药丸的黄色交通灯均执行系统任务栏最小化，绿色交通灯才负责药丸/卡片切换。最小化开始后停止尺寸动画和分层窗口整帧提交，直到 Windows 报告窗口恢复；托盘“显示”使用同一恢复入口，防止待绘制帧让窗口闪回桌面。
- 丰富词典、四条以上截图行或实际内容高度超过紧凑阈值时，卡片自动使用 350×420px 阅读尺寸，不再展开到 500px 大卡片。顶部空白区域可直接拖动；正文无结果或内容无需滚动时，空白处长按 280ms 开始移动。需要滚动的正文、搜索框及按钮不得被移动手势抢占。
- 卡片与药丸的四边命中带为 10 逻辑像素，四角辅助区上限为 38 逻辑像素，并限制在当前宽、高各自的三分之一内，防止矮药丸的对角区域吞掉整条侧边。鼠标进入命中带立即切换水平、垂直或对角缩放光标，并显示低透明蓝色柔光轮廓；离开命中带进入正文时必须在同一次移动事件中恢复默认箭头，不得继承最后一次边缘形状。按下后轮廓增强，Platform 层持续捕获指针至松开，避免快速拖动时丢失边框。
- 卡片采用 220×200px 紧凑状态与 350×420px 阅读状态。无数据、翻译等待和仅有核心释义时保持紧凑；出现例句、同反义词、词形变化，或截图结果达到四组以上时同步调整宽高进入阅读状态。尺寸切换为 180ms `OutCubic`；手动拉伸期间不得自动抢占尺寸。
- 标准空卡片默认宽度为 220px，展开时不强制回到旧的 340/380px；用户手动拉伸后的卡片宽度继续独立记忆。翻译等待使用居中的蓝、紫、绿三点轻波动，不显示状态口号；结果在 180ms 内淡入，并从下方 7px 于 220ms 内归位，使用 `OutCubic` 保持克制。
- 空状态提示占满搜索框下方的可用正文页，并在该区域水平、垂直居中；进入时以 700ms 淡入并从下方 6px 归位，完成后保持完全静止，不循环改变透明度或位置。动画不改变布局尺寸，不推动搜索框或底栏。
- 搜索框获得焦点时，卡片外沿立即以 10% 初始能量亮起蓝、紫、粉、琥珀与翠绿连续光谱，再用 700ms 扩散至聚焦强度；输入期间保持浅呼吸，提交翻译后提升亮度和呼吸深度。只有搜索框失焦且翻译结束后，才进入 850ms `OutSine` 消散。
- 轮廓使用约 1.5 逻辑像素的柔和彩色细光；逐像素圆角距离光场按高斯与指数曲线向内扩散 18–34 逻辑像素，中央 60% 以上区域保持清透。低饱和蓝、紫、粉、暖金、薄荷色使用平滑曲线插值并叠加极低幅度明暗变化，完整漂移周期为 14.8s，呼吸周期为 3.8s；禁止短线拼接、颗粒光点、硬色块和快速匀速旋转。
- 彩色边缘属于原生窗口外壳，绘制在既有 GDI+ 整帧合成中；QML 只提供时序与强度参数。不得用 Canvas、ShaderEffect 或扩大透明窗口替代，以免软件场景增量绘制破坏右边、下边和圆角稳定性。
- 空状态提示在搜索框下方的正文页面中水平、垂直居中，不按固定顶部间距定位。首次出现以 700ms 淡入并从下方 6px 归位，动画结束后不再移动或改变透明度。
- 翻译活动边缘使用蓝、紫、粉、金、绿五色环绕光谱。最外层为 1.5px 内侧描边，柔光由边缘向内最多扩散约 20px，中央 60% 以上区域不绘制颜色，确保提示和结果文字清晰。生命周期固定为 700ms 唤醒、3.8s 往复呼吸和 850ms `OutSine` 消散。
- 主窗口继续使用 `QQuickRenderControl + QImage` 软件场景以保持 Windows 分层窗口和拉伸边界稳定。Platform 层按窗口尺寸和圆角缓存距离、方位数据，卡片与药丸共用透明像素光场并合成到各自原生外壳；不引入软件后端不支持的 ShaderEffect，也不把主窗口切换为 GPU 后端。动画结束后停止相位更新和重绘。点击任一模式的搜索框即以 700ms 唤醒流光，保持 3.8s 呼吸，失焦且不再翻译时以 850ms 消散。
- 单词头下方不显示考试范围缩写标签；英文释义保留。内容顺序固定为主释义、双语例句、词形变化、同义词、反义词。词汇区按可用宽度除以每栏最低可读宽度，实时选择 1–3 个等宽栏；不存在的区块不占栏，空间不足时自动恢复纵向顺序。
- 非最小卡片内容溢出时保留 6px 交互区域和 4px 圆角滑块；静止态滑块完全透明，只在滚动或直接悬浮时以 110ms 淡入。正文任意位置接收鼠标滚轮与触控板滚动：滚轮档位以 56px/档做短缓动，触控板按像素直接跟手。最小卡片隐藏滑块，避免侵入大圆角边缘。
- 卡片与药丸搜索框统一使用 26px 高、13px 半径、1px 描边的液态玻璃胶囊，内层以连续纵向冷蓝漫反射形成玻璃层次，不叠加横贯顶部的白色直线。卡片保留正文区的完整可用长度。无论药丸被拉伸到何种允许宽度，点击搜索区域都应立即展开编辑并获得光标。卡片与药丸聚焦时使用轻微蓝色描边和清晰蓝色光标；光标保持约 480ms 亮、430ms 暗并以 70ms 柔和切换，失焦后停止。空状态使用 15px“开始翻译”和 11px“输入文字，或直接划词”，降低口号感与视觉重量。搜索框使用“输入文字”，药丸使用“输入、粘贴或划取”，不重复操作步骤。所有输入、正文和中英文混排使用 `Microsoft YaHei UI`，音标与数值使用 `Cascadia Mono`。

- 主卡片恢复 `f7de52d` 阶段的工具栏层次：左侧红绿灯，中间语言与引擎状态，右侧截图、置顶、音乐和设置。红绿灯按紧凑状态独占固定 40–44px 区域，任何右侧收缩或悬浮状态都不得改变其位置或覆盖它。语言与状态作为一个整体，以红绿灯外框右沿和右侧图标区域左沿之间的间隔中心为锚点；拉伸每一帧及右侧图标逐步裁入时都按两个实时边界重算位置。正常缩窄时中间组先从 138px 压到 54px 且不隐藏，继续缩窄后右侧 104px 容器从左端开始裁切，截图、置顶、音乐依次像被吸走，最右端设置保留为至少 26px 的悬浮热区。
- 卡片红绿灯在正常与最小状态复用同一轻薄磨砂外框：默认 28×15px 与 5px 灯点，悬浮后扩展至 34×18px 与 7px 灯点，不为最小状态增加第二层外框。标题栏仍固定保留 40–44px，不随右侧操作变化，使语言选择器与红绿灯之间始终留有可见间距。普通卡片右侧功能组保持无外框图标排版；只有最小卡片右上角展开时使用低不透明磨砂胶囊承载按钮，避免与下层搜索框混合。点击卡片音乐图标直接收起为药丸并切入系统音乐模式。
- 卡片搜索框只在编辑时保持活动焦点和闪烁光标；点击搜索区域之外的卡片内容会把焦点交回卡片，不残留静止光标。
- 语言和引擎分别拥有独立悬浮区域：悬浮语言只把语言选择器展开到完整模式，引擎保持圆点；悬浮引擎只展开引擎名称，语言保持当前紧凑模式。右侧工具为当前展开项让位，三组之间至少保留 4px 内部间距且不得互相遮挡。
- 卡片语言选择与展开后的引擎状态统一为 22px 高、11px 圆角和 9px 标签字号；引擎压缩为圆点时使用 14×14px 轻量承载层和 5px 状态点，并与语言选择器作为一组共同居中。顶部右侧按钮使用 24×24px 实际命中框，放在各自 26px 布局槽中，左右至少留 1px 安全距离，禁止截图与置顶按钮的点击范围重叠。右侧图标下沿作为分隔线垂直位置的基准；只允许向下移动顶部控件收紧间距，不改变分隔线到搜索框的 5px。
- 悬浮最右侧热区时，右侧工具组固定右边缘向左展开，中间组可被临时挤掉，红绿灯保持不动。图标沿用药丸的透明度揭示，不叠加独立缩放：外层容器使用 160ms `OutQuart`，单项透明度使用 100ms `OutCubic`，按钮点击继续使用共享的即时按压与回弹反馈。鼠标移出后恢复当前窗口宽度对应的正常状态，手动拉伸时禁用这些补间。
- 最小卡片搜索框固定距窗口顶部 5px，24px 高搜索框置于 34px 顶部区域中，上下各保留 5px，文字使用 11px。左上和右上未展开时只在顶部 18px 接收揭示意图，减少经过正文或搜索框时误触；展开后保持完整 34px 操作高度。左侧红绿灯复用正常卡片的外框；右侧展开使用低不透明磨砂胶囊。两侧互斥，展开时搜索框继续显示低对比磨砂轮廓，内部文字与图标柔和降至 38%，不再完全隐藏。搜索框获得焦点后暂停角落展开，保证编辑清晰。三个边缘入口均先等待 110ms 悬浮意图，再使用 190–210ms `OutQuart` 宽度过渡和 140–150ms `OutCubic` 透明度过渡；普通窄卡片的最右 32px 同样由原生局部坐标识别，不要求图标先可见。
- 最小卡片两侧控件都未展开时，隐藏标题栏不得保留任何鼠标命中层，搜索框必须直接接收点击；任一角落控件完成意图延迟后，顶部控件层再升到搜索框之上。普通卡片使用接近全宽的横向分隔线，仅在左右各留 5px 保护大圆角；顶部控件下沿到分隔线、分隔线到搜索框均保持 5px，形成对称的垂直节奏。紧凑标题栏至少 44px 高，避免图标进入顶部圆角透明区。
- 非最小模式且高度达到 160px 时，底部显示单层功能栏：左侧为 Smart-Select，右侧依次为复制、朗读、收藏、历史与文字大小。按钮数量由底栏实际剩余宽度计算，能容纳就继续显示，只有确实放不下时才按优先级收起；文字大小始终保留。文字调节面板从底栏上方向上展开，语言方向和实时窗口尺寸状态行不再显示。
- 底栏左右安全边距不得小于 12px。“页面比例”控制范围为 70%–150%，同时作用于正文、搜索字号、主要留白和工具栏密度。面板使用独立 212×76px 液态玻璃工具窗；标题、当前比例徽标与关闭按钮占一行，缩小、滑杆与放大占一行。面板在窗口显示后按底栏文字按钮的屏幕坐标定位到按钮下方，不占用或遮挡正文；靠近屏幕底部时先上移主卡片再保持向下打开。
- 只复用旧版的排版与交互含义。窗口拉伸期间所有基础宽度直接由当前尺寸计算，不对弹簧和基础占位增加补间动画。
- 页面排版工具窗是卡片的固定附属面板：顶边始终位于主卡片底边下方 2px，水平位置继续对齐底栏文字按钮；主卡片移动、缩放或自动改尺寸时同步跟随。面板自身没有拖动区域，避免脱离卡片成为无归属浮窗。

### 多语言选择

- 顶部语言胶囊点击源语言或目标语言后，在控件下方打开 148px 宽、最多五行可见的紧凑液态玻璃列表。弹窗始终约束在主卡片原生边界内，避免窄卡片裁掉左侧名称；滚轮、触控板与拖动均可纵向浏览。弹窗打开期间顶部语言胶囊保持当前展开状态。源语言首项为“自动检测”，目标语言不显示自动项；列表使用简体中文全称与短语言代码，当前项以轻量蓝色选中态标识。
- 顶部胶囊始终使用英文标识 `AUTO / ZH / EN / JA` 等，列表内继续显示简体中文全称，兼顾紧凑布局与可理解性。
- 右侧功能区保留原有连续宽度动画、最右侧悬浮展开和逐项吸入顺序。已经完整容纳的按钮始终保留；只隐藏当前进入裁切边界的那一枚图标，禁止显示半枚图标或残影。其余按钮的位置、动画与交互逻辑不变。
- 常用语言覆盖简体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语、阿拉伯语、越南语和泰语。顶部胶囊只显示短标签，避免多语言名称破坏窄卡片布局；选择已有文本的新语言后立即重新翻译。
- 药丸音乐模式在宽度达到 300px 时按“上一首、播放/暂停、下一首、切回翻译”排列；空间不足时同时收起上一首和下一首，保留播放与返回，避免按钮与歌名歌词重叠。

### 截图框选与结果

- 进入截图时先隐藏翻译卡片，140ms 后捕获鼠标所在屏幕，避免把自身窗口拍进图片。框选层覆盖该屏幕，选区外使用约 45% 黑色遮罩，选区边缘使用 2px 蓝色描边。
- 指针按下后立即出现选区，拖动过程逐帧跟手，不使用位置补间。选区最小为 8×8 逻辑像素；Escape 立即取消并恢复主卡片。
- 松开鼠标后恢复同一个翻译窗口并展开为卡片，顶部、底部、圆角和缩放行为保持不变；卡片正文原地切换为截图结果，不新增工具窗口。OCR 和翻译期间使用活动指示与明确状态文字。
- 双语正文按“原文、译文”的阅读顺序连续排列，不使用组内或组间分隔线；长内容按正文可用宽度自然换行，并在现有卡片内纵向滚动。异步内容保留稳定正文空间，避免结果到达时推动顶部和底部工具栏。
- 原截图默认在正文上方显示为不超过 82px 的紧凑缩略图；眼睛按钮只控制缩略图显隐，点击缩略图在独立液态玻璃预览窗中放大查看，不改变截图结果卡片尺寸。正文不使用小卡片、序号、语言标签或分隔线：每组先显示 13px 较粗白色原文，下一行显示 13px 常规灰白色简体中文译文；组内间距 1px、相邻双语组间距 2px，保持接近普通文章的紧凑阅读节奏。OCR 行逐条翻译并渐进出现，保持真实的一对一关系；失败时显示真实错误并允许重新框选。
