### 本轮发现并修复的逻辑错误

- Windows 首次显示后可能替换窗口过程，造成主窗口内容区偶发收不到点击；现在同时注册原生事件过滤器并重新确认挂接。
- 鼠标按下曾使用另一时刻的全局指针坐标做边框命中，快速点击可能被误判为缩放；现在按下使用事件自带坐标，悬浮光标才读取全局位置。
- 中文输入焦点只停留在离屏场景，系统输入法无法找到真实宿主；现在真实窗口公开最终 QML 焦点对象并转发输入法查询与提交。
- 语言切换后的旧异步响应可能覆盖新结果；现在 AppState、调度器和 Provider 均按请求代次丢弃迟到响应。
- 备用翻译引擎失败时曾错误重试首选引擎；现在重试绑定当前实际 Provider。
- 外置页面排版面板曾读取 Qt 的旧逻辑位置；现在使用实际原生窗口矩形定位，并在显示期间跟随移动和缩放。

### 需要真实环境继续确认

- 系统媒体封面、进度、上一首/播放/下一首取决于当前播放器是否公开 Windows GSMTC 数据；本轮环境没有可用于验收的活动媒体会话。
- Gemini、DeepL、有道需要用户自己的密钥，本轮验证了无密钥降级链和免密方向，没有调用私人密钥服务。
- 当前自动化桌面会话后段无法读取屏幕像素和系统光标句柄，因此八边轮廓截图探针未能在这一环境重跑；QML 连续圆角与缩放轮廓测试通过，真实边框仍应以用户桌面拖动体验为最终验收。
- 安装包尚未代码签名，Windows 可能显示来源提示；SHA-256 文件用于核对下载完整性。
